# Archipelago Details
## Win Conditions
In the YAML, players will be able to select a basic point accumulation win condition, but will also be able to choose to win from amount of main characters clearing the game as well as a specific main character **(need better wording here)**.

## Locations
Each augment node on the map will provide a check. Additionally, victory against the boss will provide a check especially for higher ascension goals as potential win conditions.

## Items
Each augment in the game will be provided as items, with the YAML option to include how many of a given stackable augment are available in the pool. All augments will be deemed useful, and progression items will include things such as Characters, Ascensions if that is a toggled win condition, and abilities if an AbilitySanity option is picked (Plans to restrict S1, S2, Block, Parry, Grab, Supers, and Ultimates). Junk will mostly be filler, but could potentially include some lower tier augments or a custom augment so they still have some meaning.
